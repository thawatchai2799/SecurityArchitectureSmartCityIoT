# MANIFEST — every table and figure, its experiment, its script and its result file

Release v2.2.0 (second peer-review revision of manuscript smartcities-4547789).
Added for Reviewer 1's round-2 Comment 5: one canonical regeneration path.

Two script families produce the numbers in the manuscript and in the Supplementary Material:

* the **original pipeline** — `run_poc.py`, `run_extended.py`, `run_advanced.py`, then
  `paper_src/make_facts.py` (collects `results/*.csv|json` into `results/paper_facts.json`) and
  `paper_src/make_figures.py`;
* the **review-response harnesses** in `review_response/` (and `fabric/bench/decode_blockfile.py`),
  added during the two review rounds, each writing its JSON next to itself.

Where a review round replaced a protocol, the original pipeline now applies the revised protocol
(Table 13: `run_extended.py --part C` runs seeds 42–44 and averages the last three rounds, exactly as
`review_response/table13_perseed.py` does; E11: `run_extended.py --part D` measures the commit latency
in the replay itself).  No script writes a reported result file under an older definition.

"Canonical" = the file the manuscript number is read from.  "Archived" = a superseded run kept under
its own name so that the effect of a correction can be seen; archived files are never read by any
script.  All federated experiments use the shipped `data/TON_IoT_Train_Test_Network.csv`; the
60k-flow sample is `load_ton_iot(sample=60000)` with the 70/30 stratified split, `random_state=42`.

## Regeneration order

1. `python check_env.py`
2. `python run_poc.py` (E1, E3, E4, E6–E8, E10, E12; ≈ 20 min)
3. `python run_extended.py --part A --seed 42|43|44`, `--part B`, `--part C`, `--part D`, `--part fig`
4. `python run_advanced.py --part R`, `--part A --n-att 1`, `--part A --n-att 2`, `--part T` (needs CIC-IDS2017 per-day files)
5. `cd review_response` and run the harnesses in the two tables above (each is independent; the slowest are
   `fk_boundary_sweep.py` ≈ 16 min and `table13_attacker_placement.py` ≈ 9 min on the authors' laptop)
6. `python paper_src/make_facts.py`, `python paper_src/make_figures.py`, `node paper_src/make_supp.js`
7. E13/E22 need the Fabric test network (`fabric/README.md`); their files are committed.
